# Capturas de tela do protótipo

Coloque nesta pasta as imagens do front-end que serão exibidas no README principal.

Sugestões de nomes:

- `painel-banco.png`
- `assistente-guiado.png`
- `consulta-saldo.png`
- `extrato-exemplo.png`
- `alto-contraste.png`

Use arquivos PNG, JPG ou WebP, preferencialmente com nomes sem espaços e sem acentos.

No README da raiz, insira cada imagem assim, depois de adicionar o arquivo:

```markdown
![Painel inicial do Banco Nexo](docs/images/painel-banco.png)
```
